# tgjt —— Telegram 群图片视频归档器

一个跑在自己电脑上的 Telegram 个人归档器：把受保护群里的图片和视频长期存下来，
在自己手机/电脑上随时翻看，不用再翻聊天记录。

## 它解决什么问题

| 痛点 | 这工具怎么解决 |
|---|---|
| 受保护群开了「禁止保存」（noforwards），官方客户端长按没有「保存到相册」 | 不走「保存」，直接以自己的账号收媒体文件 |
| 群里几百个话题，想找一张以前看过的图要在手机上一层层翻 | 网页画廊：按话题/作者/类型筛选，最新的永远在上面 |
| 有人删图，或把消息编辑成别的东西 | 删除只做标记、文件保留（有「只看已删除」和一键清理）；编辑历史把**原图和每一版**都存着，点「已编辑」能一路翻回去 |
| 同一张图被反复转发，存成几十份 | 按 SHA-256 内容寻址，同一文件整个库里只落一份盘 |
| 电脑下班盖盖子就断 | 服务运行期持系统电源请求，电脑不进待机（屏幕该黑还是黑） |

## 功能一览

- **实时监听 + 兜底补漏**：新消息靠推送事件收；每 10 分钟按游标扫一遍漏掉的补上（只有扫描推进游标）。也能手动「补历史 / 补最近 N 小时」把旧消息拉下来。
- **只收图片和视频**，单文件超过上限（默认 100 MB，可调）只记个号、不占盘。
- **内容寻址去重**：文件按 SHA-256 落 blob，同一张图无论谁转发、贴在哪个话题都只存一份；画廊里把重复折叠成一个卡片。
- **相册聚合**：连续发成一组的是一个相册卡片（图和视频可以混着）。
- **编辑历史保留**：卡片主图永远是原图，「已编辑」能展开「原图 → 中间各版 → 现在」，每张都能点开看大图。
- **删除同步**：Telegram 那边删消息，这里只标「已删除」，文件仍保留。
- **筛选**：类型（图片/视频/下好的/等待中/跳过/已删除/已编辑/收藏）、作者、话题，实时生效。
- **左栏群列表**：群/频道一键筛选 chips、真头像（photo 标识没变就不重下）、开着监听的置顶。
- **按话题监听**（论坛群）：设置里「只收这些话题」多选下拉，可与作者白名单叠加（两者都要过）；General 用 `general` 进名单，留空收全部。
- **灯箱**：点卡片进，←→/滚轮跨卡翻页、Esc 关；媒体右上角「删除」一次删一张（索引和文件一起删，删完接着看下一张）。
- **编辑模式**：点「选择」进，点卡片选中、底栏全选/清空/删除所选；批量删完留在选择模式，点「完成」才退。
- **两个页签**：列表（画廊）与统计（作者/类型/状态分布）。
- **导出**：导出清单（CSV）、打包 zip、静态离线页（拷到手机也能看的单文件 HTML：瀑布流/筛选/灯箱/历史版本）——三个都跟随当前筛选。
- **本机专属**：点「打开文件夹」在资源管理器里定位文件、「本地打开」用系统默认程序打开（图片看图器、视频播放器）。
- **磁盘上限**：设个 GB 数，到上限就暂停下载并在界面提醒。
- **局域网访问**：手机连同一个 WiFi 直接用（要设访问密码）；窄屏自动换成底部标签页布局。
- **凭证加密落盘**（下一节）。

## 快速开始

> Windows 专用（凭证加密用 Windows DPAPI）。Python 3.11+，实测 3.12。

```bat
:: 1. 装依赖（就这两个，其余全是标准库）
pip install -U telethon qrcode

:: 2. 双击 run.bat —— 后台无窗口启动，自动打开浏览器
```

3. 首次打开的页面里：
   - 去 <https://my.telegram.org> → API development tools，申请**你自己**的 `api_id`（顺带拿到 api_hash）。
     以后每次运行只要 `api_id`；`api_hash` 只在（重新）登录时才用得上，重登时才在设置里填一次。
   - 填 `api_id` → 保存 → 出二维码 → 手机 Telegram：**设置 → 设备 → 关联桌面设备** 扫一下。
     开了两步验证的话会要求再输一次那个密码。
4. 手机访问：同一 WiFi 打开 `http://<电脑局域网IP>:8787/`。
   **先在设置里设一个访问密码** —— 服务监听在 `0.0.0.0`，同一 WiFi 内知道地址的人都能打开这个页面。
5. 停止：双击 `stop.bat`。

进阶：`pythonw -X utf8 server.py --port 9000 --root D:\某目录 --no-browser` 可换端口、换库目录、不自动开浏览器。日常只需要两个 bat：

- `run.bat`：没在跑就后台启动（日志写 `_run.log`），已在跑就只打开页面；关掉窗口**不会**停服务。
- `stop.bat`：按 `_server.pid` 停掉服务。

登录成功的标志：页面从「正在连接」变成正常列表；`_run.log` 里出现「归档服务已启动」。

## 凭证与安全

落盘的只有密文，明文只活在服务进程的内存里：

1. **默认档（不设口令）**：数据库里的 `api_hash` 和 Telegram session 都用 **Windows DPAPI**
   （`CryptProtectData`）加密，绑定当前 Windows 账户 —— 重启自动解开、零操作。挡得住「复制你家文件」的
   木马，**挡不住**以你这个账户身份运行、还会调 DPAPI 的木马。
2. **可选档（启动口令）**：口令先过一遍 scrypt（n=2^15, r=8，每次约 120 ms）再作为 DPAPI 的
   **次要熵**，没有口令谁也解不开凭证库。代价：每次重启都要在这台电脑的网页上输一次口令 ——
   锁着时手机端所有库接口返回 423（口令绝不能走明文 HTTP 的局域网）。输错 5 次锁 30 秒；
   忘了口令只能「重置并重新登录」。

## 它怎么工作

```text
archive\
├── server.py        本机网页服务（纯 HTTP，默认 127.0.0.1:8787，可选绑到局域网）
├── watcher.py       Telethon 客户端：实时监听、补漏扫描、下载与断点续传
├── store.py         每个群一个小 SQLite + 全局索引（设置/游标/加密凭证都在 settings 表）
├── gallery.py       导出静态离线页（单文件 HTML：瀑布流/筛选/灯箱/历史版本）
├── tg.py             Telegram 侧小工具（链接解析、频道判定、话题定位）
├── secure.py         凭证加密：DPAPI / scrypt(口令) 作为次要熵
├── web\             前端（纯 JS+CSS，无构建步骤）
├── run.bat / stop.bat
└── library\         ← 归档的库（**永不进仓库**，见 .gitignore）
    ├── index.db                     全局设置
    └── -1001234…\                   一个群一个目录
        ├── index.db                 这个群自己的消息索引
        ├── files\<sha256前两位>\…   内容寻址的媒体文件（去重靠它）
        ├── by-author\…              硬链接，按作者浏览（不占第二份磁盘）
        └── thumbs\…                 Telegram 自带的压缩缩略图
```


- **去重按文件本体**（file_uid/SHA-256），不因内容遭编辑而错杀唯一一份原件。
- 下载失败偏保守：`.part` 断点续传（1 MiB 对齐）+ 退避重试；只有「消息已删/撤回」才标失败，
  其他错误永远重试。
- Windows Modern Standby 会挂起后台程序 —— 服务运行中常驻
  `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)`，醒来后在日志里标注
  「本进程刚被挂起过约 N 秒」。
- 界面自动适配窄屏：JS 按 `min(innerWidth, screen.width) ≤ 860` 定宽，切到手机/平板布局。

## 已知限制


- **只有 Windows 单用户**（依赖 DPAPI）。
- **单账号**，无多用户权限：同一 WiFi 内能看见页面的人都用同一把访问密码。
- 只保留媒体的编辑历史；纯文本编辑只更新最新正文。
- 会话列表最多拉 500 个（`iter_dialogs` 上限）；更老的不在左栏。
- 监听白名单（作者/话题）只管往后进来的消息，**不追溯**已入库的旧消息。
- **userbot 的 ToS 风险**：Telegram 官方对自动化不持鼓励态度，过量自动化可能被限流或封号。


## FAQ。

**电脑睡眠了服务会漏消息吗？**
不会漏（醒来会自动补上），但睡眠期间手机连不上。正常情况下本项目会让电脑根本不睡眠；
日志里出现「本进程刚被挂起过」就意味着发生过一次异常挂起。

**页面一直锁着？**
设了启动口令就是这样 —— 口令只能在**这台电脑**上输入（锁着时手机端全部返回 423）。

**api_hash 什么时候才要填？**
只在重新登录时。session 还活着时它一次都不发，日常根本不用管它。

**改了代码怎么生效？**
`stop.bat` → `run.bat`。前端文件是服务每次从盘上现读的，浏览器 Ctrl+F5 就能刷到新版本。
